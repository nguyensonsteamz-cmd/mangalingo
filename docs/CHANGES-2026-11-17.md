# Changes of 2026-11-17 (Chrome + iPhone)

## Product decisions
* **Translation providers**: Google Cloud Translation first (BYOK); when the monthly quota is used up the user decides (stop → Chrome Translator on Chrome / Apple Translation on iPhone, or allow paid translation). The downloaded OPUS-MT model is **switched off** (code kept, `setLocalModelEnabled`).
* **First use**: Google sign-in gate (Smart Setup OAuth) on Chrome (side panel, Settings, toolbar popup, page popup) and on iPhone. Android unchanged. When a build has no OAuth client id the gate explains it and offers "continue for now" (so nobody is locked out of a build that cannot sign in). Existing users with a Google key are not asked again.
* **iPhone secondary provider (proposal, implemented)**: Apple Translation (on-device, free, offline after the pack download, en↔vi). It is already the fallback; OPUS-MT stays off on iPhone.

## Chrome
Notes = own sidebar tab, **auto-saved** to notes and the vocabulary notebook (re-wording an entry replaces, never duplicates), grouped by day (Hôm nay / Hôm qua / Thứ …, dd/MM/yyyy); the vocabulary list is grouped the same way. Copy button on cards (original text, translation, popup headers, vocabulary, notes). A new lookup makes the sidebar start on the Dịch tab (it kept the previous tab before). Popup: drag the grip to move, drag the corner to resize. OCR: editing a bubble re-reads only that bubble (already so; now tested that the others stay), new **"＋ Thêm bong bóng"**: drag a rectangle over missed text, only that area is read, an empty bubble opens for typing when nothing is readable. Speech: long text is spoken sentence by sentence (Chrome cut long utterances), local voices first.

## iPhone
* Settings: vertical list of rows → detail page with a back button.
* Speech (Speaker.swift): sentence pieces, queue-safe stop (starting a new text right after a stop made words / sentences silent), audio session released afterwards. **Compile verified, not heard on a phone.**
* Web Reader: **tabs** (strip, list, new / close), kept when the Reader is closed and across app restarts; target=_blank opens a new tab; script pop-ups are blocked with "Vẫn mở"; Back skips duplicate history entries; "Quay lại trang đang đọc" after a cross-site redirect; ad-network content rules; invisible full-screen overlays are switched off for the tap (JS unit-tested in Chrome); setting "Chặn quảng cáo".
* Tools drawer ("touch"): vertical column — translate selection, scan image, scan region (adds bubbles), scan screen, scan all images, sidebar, notes, bookmark.
* Sidebar: the extension's sidebar in a second web view (#reader-sidebar), receives the popup's "Chi tiết" and the scanned bubbles.
* Tool column of the scan page (Assist) is vertical too.
