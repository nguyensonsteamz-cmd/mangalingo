## Paths to a phone
**A. Today, no paid account (works now):** download `LingoLens.ipa` (CI artifact) → install with Sideloadly using your Apple ID → app valid 7 days, re-sign weekly. Suitable for the physical-device test pass.
**B. TestFlight / App Store (needs the paid Apple Developer Program):**
1. Confirm the bundle id `app.mangalingo.ios` (changing it later is impossible after the first upload) and create the App ID in the developer portal.
2. Create a Distribution certificate (Keychain on a Mac, or via App Store Connect API key) and an App Store provisioning profile for that id.
3. Set `DEVELOPMENT_TEAM` and switch to the profile in project.yml (or pass them to `xcodebuild`), raise `CFBundleVersion` for every upload.
4. `xcodebuild archive -project ios/MangaLingo.xcodeproj -scheme MangaLingo -configuration Release -archivePath build/LingoLens.xcarchive` then `xcodebuild -exportArchive -archivePath … -exportOptionsPlist ExportOptions.plist -exportPath build/export`.
   ExportOptions.plist (no secrets): `method=app-store-connect`, `teamID=<TEAM>`, `signingStyle=manual`, `provisioningProfiles={app.mangalingo.ios: <profile name>}`, `uploadSymbols=true`.
5. Upload with `xcrun altool` / Transporter / `xcodebuild -exportArchive` with an **App Store Connect API key**; test in TestFlight before submission.
6. In CI: certificate (.p12) and profile as base64 secrets, import into a temporary keychain, build, delete the keychain; never for fork PRs.
7. App Store Connect: privacy nutrition label (text goes to Google only with the user's own key; optional model download from Hugging Face), encryption answer (exempt flag already false), screenshots, review notes explaining the Shortcut action.
